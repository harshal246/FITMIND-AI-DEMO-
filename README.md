# FITMIND-AI-DEMO-

FitMind AI — Autonomous Athletic Intelligence Platform Showcase

Full-page, luxury frontend showcasing all 11 core functional requirements, dual Ambilight cinema presentation displays, interactive biometric readiness calculators, multi-agent AI coaching playground, and real-time workout telemetry.

## Features
- **3D Hero Perspective Cockpit**: High-gloss Central Command dashboard display with floating live biometric telemetry.
- **Dual Cinema Theater Showcase**: Pre-wired for 4K video presentations with Ambilight backlights and interactive chapter scrubbing.
- **One-by-One Functionality Cards Deck**: Detailed breakdown of all 11 modules (FR-01 through FR-11) complete with visual graphs (TDEE partitions, token rotation timelines, 7-day HRV trajectories, macro cycling, progressive overload steppers, and recovery decay curves).
- **Interactive Simulators**: Morning Readiness calculator (FR-03), Multi-Agent AI Coach with LangGraph reasoning trace (FR-06), and in-gym workout rest countdown clock (FR-05).
- **Multi-Agent Architecture**: Full-stack specifications and security audit hardening standards.

## Tech Stack
- React 19
- Vite 8
- Vanilla CSS (Obsidian & Titanium Design System)
- Lucide Icons

## Quick Start
```bash
npm install
npm run dev
```
